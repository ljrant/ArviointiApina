What it does

A practical course-grade workflow

Import from Abitti

Reads student names, emails and total scores from Abitti review pages. Maximum points stay explicit instead of being guessed.

Multiple courses

Keep several classes and courses in one local utility and switch between them from the panel.

Weighted assessments

Give exams, quizzes and other work different weights, then calculate a weighted course percentage.

Per-student exceptions

Exclude or reweight an assessment for one student without changing the course defaults.

Name-first matching

Match by exact/fuzzy name first, then email. Abitti UUID is only a last-resort hint because it may change between exams.

Backup and export

Export course CSV for spreadsheets and full JSON backups for moving data between browsers or devices.

Privacy

Local-first by design

ArviointiApina stores gradebook data in the userscript manager's local storage. It does not require an ArviointiApina cloud account or send student data to an ArviointiApina server.

Protect your browser profile and exported backups appropriately because they can contain student assessment data.

Project direction

Userscript first. Browser extension later.

This repository is primarily the development home of the Tampermonkey userscript. The existing Chrome-extension prototype remains experimental and may later become a standalone browser extension/app using the same gradebook model.
